# 🚀 Portfólio de Melchisedek Lima

Este é o código-fonte do meu portfólio profissional, um espaço digital onde mostro meu trabalho como **Desenvolvedor Front-end** e **UI/UX Designer**. A intenção aqui é apresentar minhas habilidades e projetos de forma clara e profissional.

---

## ✨ Por que ele foi feito assim?

Este portfólio foi cuidadosamente desenvolvido para ser mais do que apenas um site:

- **🎨 Design Responsivo**: A interface foi pensada para se adaptar perfeitamente a qualquer dispositivo, do desktop ao celular
- **⚡ Performance Otimizada**: Cada detalhe foi ajustado para garantir um carregamento rápido e uma experiência fluida para o usuário
- **♿ Totalmente Acessível**: O código segue as normas WCAG 2.1, garantindo que o conteúdo seja acessível para todos
- **📱 PWA (Progressive Web App)**: Ele pode ser instalado como um aplicativo, funcionando até mesmo offline
- **🔍 Otimizado para SEO**: A estrutura e as meta tags foram configuradas para um bom posicionamento nos motores de busca
- **📧 Formulário de Contato Inteligente**: Um sistema seguro de envio de e-mails, com validação e proteção contra spam
- **✨ Animações Suaves**: As transições e animações foram otimizadas para dar um toque de modernidade sem comprometer a performance

---

## 🛠️ Tecnologias Utilizadas

O projeto foi construído com as seguintes ferramentas e tecnologias:

### Front-end
- **HTML5, CSS3** e **JavaScript (ES6+)** para a estrutura, estilização e interatividade
- **Font Awesome** para ícones
- **Google Fonts** para tipografia

### Back-end
- **Node.js** e **Express.js** para o servidor
- **Nodemailer** para gerenciar o envio de e-mails
- **Helmet** e **CORS** para segurança

### Ferramentas de Apoio
- **ESLint** para manter o código limpo
- **Nodemon** para agilizar o desenvolvimento
- **Service Worker** e **Web App Manifest** para PWA

## 🚀 Como Executar

1. **Clone o repositório**
   ```bash
   git clone https://github.com/melchisedek/portfolio.git
   cd portfolio
   ```

2. **Instale as dependências**
   ```bash
   npm install
   ```

3. **Configure as variáveis de ambiente**
   
   Crie um arquivo `.env` na raiz do projeto:
   ```env
   EMAIL_USER=seu-email@gmail.com
   EMAIL_PASS=sua-senha-de-app
   PORT=3000
   NODE_ENV=development
   ```

4. **Execute o servidor**
   ```bash
   # Desenvolvimento
   npm run dev
   
   # Produção
   npm start
   ```

5. **Acesse o portfólio**
   
   Abra seu navegador em `http://localhost:3000`

## 📱 PWA

O portfólio é um Progressive Web App (PWA) que pode ser instalado:

- **Chrome/Edge**: Clique no ícone de instalação na barra de endereços
- **Firefox**: Clique no ícone "+" na barra de endereços
- **Mobile**: Adicione à tela inicial
